# Frontend Architecture

Kwiva owns SSR (ADR-0006):

```
GET /path
├── resolveRoute
├── layout.resolveLayouts
├── page.load (SSR)
└── renderPage → document
```

## Data flow

`page.load` → props → `renderPage` → tree → hydrateApp.

## Types

Typed via `src/.kwiva/types/route-tree.gen.ts`.
