# Architecture

## Core rule

> The application depends only on the framework; the framework owns the engines.

```
Your app (src/) — models, http, pages, jobs, events, config
  ↓ writes defineX(...) only · imports only @kwiva/*
Framework API surface (@kwiva/* — the 19 packages)
  ↓
Sealed engines (framework-owned internals — never imported by app code)
  ↓
Runtime (Bun · Node · serverless · containers) via presets
```

## Design pillars

1. **One defineX grammar** — every app construct is a factory
2. **Framework-owned APIs** — framework owns lifecycle/types
3. **Type safety throughout** — typed routes, zero codegen
4. **Batteries included, not forced** — defaults + overrides
