# Design Principles

## Pillars

| Pillar | Meaning |
|---|---|
| **Coherence over fragmentation** | One grammar, one narrative. |
| **Framework-owned APIs** | Kwiva owns the app surface; engines sealed behind. |
| **Type safety** | IR-driven types end-to-end. |
| **Convention through defineX** | One grammar for all constructs. |
| **Batteries included, not forced** | Defaults with overrides. |
