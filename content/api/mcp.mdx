# @kwiva/mcp

MCP package (v2, built on `@modelcontextprotocol/server`): config, tool generation from models/controllers, custom tools, HTTP fetch handler + stdio server.

## Config (`src/config/mcp.ts`)

`McpConfig{enabled?: boolean, route?: string (default "/mcp"), transport?: "streamable"|"stdio" (default "streamable"), auth?: "session"|"bearer"|"none" (default "session"; none only with stdio), models?: string[], controllers?: string[], readOnly?: boolean, scopes?: string[], requireTenant?: boolean}` — `validateMcpConfig` throws `KwivaError("BAD_REQUEST")`.

> [!TIP]
> With `auth: "bearer"` the handler enforces `X-API-Key`-less bearer tokens (see [auth](/api/auth) — `apiTokenAuth`); `bearer` keys come from `@kwiva/auth` API tokens.

## Tool generation

| Symbol | Notes |
|---|---|
| `generateModelTools({config, models?, executor?})` | tools named `{table}_{action}`; actions `list/get/create/update/delete`; `readOnly` → only list/get; `requireTenant` filtering |
| `generateControllerTools({config, manifest?, executor?})` | tools named `{controller}_{action}` from route manifest |
| `defineMcpTool({description?, input, ability, handler, name?})` | custom tools — `ability: "resource.action"` (e.g. `"posts.read"`) |
| `registerMcpTool(name, tool)`, `MCP_TOOL_SUFFIX = "Tool"` | — |
| `inputToJsonSchema(input)`, `validateToolInput(input, raw)` | Standard Schema → JSON Schema; validation errors → 400 with fields |

## Server (`./server`)

| Symbol | Notes |
|---|---|
| `createMcpServerHandler({config, tools, resolveScope?, logger?, rateLimiter?, rateLimitWindow?})` | `McpHandler{fetch(request): Promise<Response>}` — POST-only, 405 on GET/HEAD; session auth via cookies, bearer auth via header, audit logging |
| `runStdio({config, tools, ...})` | → `McpStdioHandle{close()}`; requires `auth: "none"` |
| `executeToolCall({tool, name, input, scope, options})` | rate limit → validate → ability → tenant → handler |
| `toolError(code, message?, fields?)`, `toolErrorFromException(error)` | — |

Rate limiting: `DEFAULT_RATE_WINDOW{max: 120, windowMs: 60000}`; returns `TOOL_ERROR` 429.

## What tools can do

Tools are policy-checked: `ability` string (`resource.action`) → `can(policy, user, action, resource)` from the app registry; `tenantId` from `currentTenant()`; results shaped `McpToolResult{content: McpTextContent[], isError?, structuredContent?}`.

> [!TIP]
> Generated tools respect `readOnly: true` — `create/update/delete` tools are excluded.
