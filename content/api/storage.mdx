# @kwiva/storage

Storage package: S3-compatible disks over Files SDK, tenant-scoped paths, signed URLs/uploads, asset helpers, fakes.

## Config

| Symbol | Kind | Signature |
|---|---|---|
| `validateStorageConfig(config?)` | function | → `ResolvedStorageConfig{default, disks, tenant?}` |
| `STORAGE_DRIVERS` | const | `["local","memory","s3","gcs","azure","vercel-blob"]` |
| Types: `StorageConfig{default?, disks?: Record<string, DiskConfig>, tenant?: StorageTenantConfig{scoped?, prefix?}}`, `DiskConfig{driver, root?, publicUrl?, options?}`, `StorageTenantConfig{scoped?, prefix?}`, `StorageDriver`, `DEFAULT_LOCAL_ROOT = "./storage/app"` | types/const | — |

## Usage

```ts title="src/app/http/controllers/files.ts"
import { storage } from "@kwiva/storage";

const res = await storage.put("avatar.png", file.arrayBuffer(), { contentType: "image/png" });
```

> [!TIP]
> Tenancy-scoped config makes `storage.disk("local").put("a.txt", ...)` prefix-scoped per tenant via `currentTenant()`.
