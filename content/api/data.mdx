# @kwiva/data

The data package: `defineModel` (one model = schema + REST + client + audit), the fluent query builder, relations, transactions, migrations, seeders, factories.

## Model definition

```ts title="src/app/models/post.ts"
import { defineModel } from "@kwiva/data";

export const Post = defineModel("posts", (f) => ({
  id: f.id(),
  title: f.string().validation((s) => s.min(1).max(200)),
  status: f.enum("draft", "published"),
  createdAt: f.dateTime(),
  author: f.belongsTo(() => User),
}), {
  timestamps: true,
  audit: true,
  routes: true,
  fillable: ["title", "status"],
  permission: "posts",
  hooks: {
    beforeCreate(record) { record.status = "draft"; },
  },
  indexes: [{ columns: ["status"] }],
});
```

**Options:** `{timestamps, softDelete, audit, tenantField?, permission?, fillable?, guarded?, hidden?, visible?, appends?, computed?, uniques?, routes, primaryKey?, search?}`.

**Fields DSL (`f`):** `id, uuid, string, text, integer, bigint, float, boolean, date, dateTime, time, enum(...values), json<T>, belongsTo, hasOne, hasMany, manyToMany, hasOneThrough, hasManyThrough, morphTo, morphMany, morphToMany`.

**Instance API:** `save/update/delete/forceDelete/restore`, `refresh`, `replicate(except?)`, `loadMissing(rel)`, `associate/dissociate`, `trashed`, `isDirty/isClean/wasChanged/getOriginal`, `toJSON`.

## Query builder

```ts
const posts = await Post.where("status", "=", "published").orderBy("title").limit(10).all();
const tag = await Post.with("author").get(5);
const paginated = await Post.page(1, { size: 20 }).with("author").cursor("title", "posts");
```

| Chain | Notes |
|---|---|
| `where/orWhere/whereIn/whereNotIn/whereNull/whereNotNull/whereBetween/whereLike/search` | `search(term, {includeRank})` (model `search` option) |
| `orderBy/orderByDesc/limit/offset/select/distinct/with/withTrashed/onlyTrashed/tenant/scope/withoutGlobalScopes/whereRecord` | — |
| `has/orHas/whereHas/orWhereHas/whereDoesntHave/withCount/withAggregate` | relation-aware |
| `firstOrCreate/firstOrNew/updateOrCreate/insert/pluck/chunk/lazy/cursor` | — |

## Transactions

`db.transaction(fn)` — nested → savepoints; `getDb()` for Kysely access.

## Migrations

```ts
import { defineMigration } from "@kwiva/data";
export const CreatePosts = defineMigration("20260101000000_create_posts", (db) =>
  db.createTable("posts", (t) => { t.id(); t.string("title").nullable(false); }),
);
```

## Seeders + factories

```ts
export const SeedPosts = defineSeeder(async ({ db }) => {
  await Post.seed([{ title: "Hello" }]);
});
export const PostFactory = defineFactory(Post, (f) => ({ id: f.uuid() }));
```

## Runtime

`configureDatabase(config)`, `closeDatabase()`, `db`, `getKysely()`, `upsert(model, match, values)`.

## REST routes

`restRoutes(Post)` → 5 specs (list/get/create/update/remove) — wired via `@kwiva/http`.

## Search (model-integrated)

Model option `search: {fields: [{field, weight?}], language?}` → FTS `.search()`, `reindexSearch`, `searchCapability`. See [@kwiva/search](/api/search).

## `./testing` subpath

`setupTestDb(models)`, `teardownTestDb()`, `truncateAll()`, `syncSchema()`, `registerFixtures({name, model}[])`.

## Database config (section `database`)

| Key | Type |
|---|---|
| `driver` | `"pglite" \| "postgres"` (required) |
| `dataDir` | string (pglite; omit = in-memory) |
| `url` / `host` / `port` / `database` / `username` / `password` | Postgres connection params |
| `pool` | `{max?, idleTimeout?, connectionTimeout?, maxLifetime?}` |

> [!TIP]
> `migrateGenerate` diffs models against the live DB; `probeSearch`/`reindexSearch` are used by `kwiva search:reindex`.
