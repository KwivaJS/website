# Rendering

Kwiva-owned SSR orchestrator (since Kwiva core owns rendering).

## Entry points

| Topic | Page |
|---|---|
| SSR (Server-Side Rendering) | [Server-Side Rendering](/docs/rendering/ssr) |
| Streaming SSR | [Streaming SSR](/docs/rendering/streaming) |
| Hydration | [Hydration](/docs/rendering/hydration) |
| Caching strategies | [Caching Strategies](/docs/rendering/caching) |
| Static Generation (prerender) | [Static Generation](/docs/rendering/prerendering) |

## Pipeline

```
GET /page
├── resolveRoute(pathname)
├── layout(resolveLayouts) → [root, ...nested]
├── page.load(ctx) → props (SSR-only)
├── layouts.render(props, ctx) → tree
└── document.render → Response
```

## Notes

- No Vite plugin — Kwiva ships `buildClientBundle` + `bunx tsc` build (ADR-0008 era).
- Islands hydrate per `data-kwiva-hydrate` attribute.
- Streaming SSR with Suspense (`streamPage`).
