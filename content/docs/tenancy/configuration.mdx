# Tenancy Configuration

File: `src/config/database.ts` (inside `database` section) — wait, actually it's the `database` section's `tenancy` key:

```ts
export default defineConfig({
  driver: "pglite",
  tenancy: {
    defaults: {
      mode: "path",          // or "domain" | "header" | "fixed" | "org" | "none"
      tenantField: "tenant_id",
      models: "*",           // or array of model names
      cache: { scoped: true },
      storage: { scoped: true },
    },
  },
});
```

## Modes

| Mode | Meaning |
|---|---|
| `none` | tenant tracking only |
| `fixed` | everyone = one tenant |
| `path` | tenant in URL path (`/t/:tenant/*`) |
| `header` | tenant via request header (`X-Tenant`) |
| `org` | tenant via org chain (nested) |
| `domain` | tenant via hostname |

## Scoping

- Models get auto-scoped by `tenantField`
- Storage, cache, jobs, broadcast — tenant-scoped

> `kwiva dev` + `X-Tenant` header for quick testing.
