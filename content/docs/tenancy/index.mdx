# Multi-Tenancy

Kwiva has tenancy-first data access: models, queries, storage, and events are automatically scoped to a tenant.

## Layer diagram

```
ALS tenant (context) → @kwiva/data (auto-scoping) → @kwiva/storage (prefix)
                                              ↓
                                      @kwiva/jobs + cache: tenant-scoped
```
