# Navigation

## `Link` (soft navigation)

```tsx
import { Link } from "@kwiva/ui";
<Link href="/about" prefetch={true}>About</Link>
```

## `useRouter` — `visit(url, {replace?, preserveState?})`, `reload()`, `back()`, `on("start"|"finish"|"error")`

## `usePage` — `{url, component, props, session}`

## `hydrateApp({pages, layouts?, events?})` — hydrate on client load

## Prefetch

`setLinkPrefetcher(fn)` — custom fetcher for prefetches (via fetchEnvelope).

## Scroll restoration

`installScrollRestoration(events, options?)` → disposer.

> [!TIP]
> `fetchEnvelope(url)` returns `{component, url, props}` for soft-nav assets.
