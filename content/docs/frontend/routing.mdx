# File-Based Routing

Routes derive from file paths in `src/ui/pages/**`.

## Route map

| File | Route |
|---|---|
| `src/ui/pages/index.tsx` | `/` |
| `src/ui/pages/about.tsx` | `/about` |
| `src/ui/pages/todos.$id.tsx` | `/todos/:id` |
| `src/ui/pages/todos/index.tsx` | `/todos` |
| `src/ui/pages/blog/$slug.tsx` | `/blog/:slug` |
| `src/ui/pages/docs/$.tsx` | `/docs/*` |

## Path params

- `$param` → `:param`
- `$` → `*` (splat, at file level, e.g. `docs/$.tsx` → `/docs/*`)
- `index` → root of directory

## Matching

`matchPath(pattern, pathname)` → `{id}` params or null. Wildcard matches multiple segments.

## Layouts

Root `src/ui/layouts/root.tsx`; nested layouts possible.

`src/.kwiva/types/route-tree.gen.ts` — regenerated by `kwiva build` and `kwiva dev`.
