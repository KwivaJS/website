# Modules & Plugins

Kwiva composes apps from composable pieces:

1. **Factories** — `defineApp/Config/Service` (core), `defineModel` (data), `defineController` (http), etc.
2. **Modules** — `defineModule` — reusable packages (see [Defining Modules](/docs/modules-plugins/defining-modules))
3. **Plugins** — `definePlugin` — lifecycle-hoc pieces (see [Application Composition](/docs/modules-plugins/composition))
4. **Addons** — registry/search/publish system — **not implemented yet** (roadmap; per project decision we skip this area).
