# The defineX Convention

## What is defineX?

`defineX` is Kwiva's unifying abstraction: every app-facing construct is a factory function producing a frozen, serializable definition (the "one definition"). Reading Kwiva app code should feel like reading a description of the product.

## Convention rules

### One construct per file

Each factory produces one unit; files export it as a named const ending in the suffix: `TodosController`, `HelloPage`, `SendReminderJob`, `CreatePostContract`, etc.

### Where files live

Auto-discovered by convention. Full map (from `discover.ts DEFAULT_FOLDERS`):

| Construct | Folder | Notes |
|---|---|---|
| Model | `src/app/models/` | flat |
| Controller | `src/app/http/controllers/` | flat |
| Middleware | `src/app/http/middleware/` | flat |
| Policy/Gate | `src/app/policies/` | flat |
| Service | `src/app/services/` | flat |
| Job | `src/app/jobs/` | flat |
| Task | `src/app/tasks/` | flat |
| Event | `src/app/events/` | flat |
| Listener/Subscriber | `src/app/events/` | flat |
| Page | `src/ui/pages/` | **recursive** (`$param`, `$`, nested dirs) |

`src/app/mcp/tools/` — MCP tools; `src/app/commands/` — app commands (CLI). `src/app/mail/` — **not** in DEFAULT_FOLDERS; config-driven via `setMailConfig` in the boot seam.

### Inline options

Every factory takes options as a **second argument or `(f) => ({...})` map** with full type inference and runtime validation. No decorators, no classes, no global registries.

### Freeze + dedupe

All definitions are frozen at runtime; duplicate names throw (`defineModel`, `bindRouteIds`, etc.).

## Discovery (how it connects)

Auto-discovery via `discoverKind(root, kind)` → scans the folder map → registers by exported const name. `assembleApp(app, root)` merges additive arrays and derives page routes from relative paths (`index` dropped, `$param` → `:param`, `$` → `*`). See [Auto-Discovery](/docs/core-concepts/auto-discovery).

> [!TIP]
> Use the generators: `kwiva make:<kind> <Name>` — 19 kinds.
