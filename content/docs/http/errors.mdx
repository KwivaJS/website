# Errors

## Error taxonomy (`@kwiva/core`)

| Code | HTTP | Throwable class |
|---|---|---|
| `BAD_REQUEST` | 400 | `BadRequestError` (implicit base) |
| `UNAUTHORIZED` | 401 | `UnauthorizedError` |
| `FORBIDDEN` | 403 | `ForbiddenError` |
| `NOT_FOUND` | 404 | `NotFoundError` |
| `CONFLICT` | 409 | `ConflictError` |
| `VALIDATION` | 422 | `ValidationError` (+ `fields`) |
| `RATE_LIMITED` | 429 | `RateLimitedError` |
| `INTERNAL` | 500 | default |

Plus storage/search: `STORAGE_NOT_FOUND/CONFLICT/INVALID/UNAVAILABLE/TENANT_REQUIRED`, `SEARCH_NOT_CONFIGURED`.

## Throwing errors

```ts title="src/app/http/controllers/posts.ts"
api.get("/:id", async (ctx) => {
  const post = await Post.findOrFail(ctx.params.id);
});
```

`error(code, message, data?)` — from `@kwiva/core`.

## Error handlers

```ts
ctx.error(code, message, fields?); // return error
```

## Error response shape

```json title="Validation"
{
  "error": {
    "code": "VALIDATION",
    "message": "Invalid input",
    "fields": { "body.title": ["Too short"] },
    "requestId": "req_abc123"
  }
}
```

## Validation issues → field map

`issuesToFields(issues)` — `Record<string, string[]>`.

## Custom error codes

Extend `ErrorCode` with `KwivaErrorOptions` — throw `error("CUSTOM", "msg")` in handler.

## Client-side

`@kwiva/client`: `toClientError(status, value)` → `ClientErrorShape{code, message, status, fields?, requestId?}`; `onError` config hook; typed discriminant by code.
