# HTTP

Framework-owned HTTP layer: controllers, contracts, middleware, routing, validation, errors, caching.

## Layer diagram

```
Elysia (HTTP server, sealed)
├── Pipeline (parse → validate → middleware → handler → output)
├── Controllers (defineController) → auto-manifest → dev-overlay wiring
├── WebSocket routes + channels
├── REST auto-routes (from @kwiva/data models)
└── OpenAPI (mountOpenAPI, Scalar at /docs)
```

## Key concepts

- **`defineController(name, routes, options)`** — one controller = prefix + routes + middleware + tags.
- **Auto-manifest** — `mountRoutes` binds route IDs (`ControllerName.verb`).
- **`ctx`** — `HttpContext`: `input{params, query, body, headers, cookies}`, `setHeaders()`, `json()`, `text()`, `redirect()`, `stream()`, `session`, `user`, `can`.
- **REST auto-routes** — `@kwiva/data` `restRoutes`: `GET/POST/PATCH/DELETE /api/{plural}` + `/:id` + `:id/actions` (5 per model).
- **OpenAPI** — `mountOpenAPI(app, manifest)` + `/docs` (Scalar) + `/openapi.json`.
