# Tool Generation

## Model tools

`generateModelTools({config, models?, executor?})` → `McpTool[]`:

| Tool name | Action | Notes |
|---|---|---|
| `todos_list` | list | GET /api/todos |
| `todos_create` | create | POST /api/todos |
| `todos_get` | get | GET /api/todos/:id |
| `todos_update` | update | PATCH /api/todos/:id |
| `todos_delete` | delete | DELETE /api/todos/:id |

With `readOnly: true` — only list/get.

## Controller tools

`generateControllerTools({config, manifest?, executor?})` → per non-WS route: `TodosController_create` etc.

## Custom tools

```ts title="src/app/mcp/tools/audit.ts"
import { defineMcpTool } from "@kwiva/mcp";

export const AuditTool = defineMcpTool({
  description: "Dump current state to audit log",
  input: { table: { type: "string" } },
  ability: "audit.read", // policy check via can(...)
  handler: async ({ input }) => { return { content: [{ type: "text", text: `audit ${input.table}` }] }; },
});
```

## Schema generation

- `inputToJsonSchema(input)` — JSON Schema from Standard Schema or field map
- `MCP_TOOL_SUFFIX = "Tool"` — naming convention
- `registerMcpTool(name, tool)` — adds suffix, returns `McpTool`

> [!TIP]
> Custom tools are discovered via `src/app/mcp/tools/**` recursive scan.
