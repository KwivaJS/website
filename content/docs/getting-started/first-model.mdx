# Your First Model

```ts title="src/app/models/todo.ts"
import { defineModel } from "@kwiva/data";

export const Todo = defineModel("todos", (f) => ({
  id: f.id(),
  title: f.string().validation((s) => s.min(1).max(200)),
  status: f.enum("pending", "done"),
  priority: f.integer().default(0),
  createdAt: f.dateTime(),
  updatedAt: f.dateTime(),
}), {
  timestamps: true,
  routes: true,
  fillable: ["title", "status", "priority"],
  permission: "todos",
});
```

## What this model derives

| Artifact | Description |
|---|---|
| Database table | From field kinds — `string` → `varchar`, `integer` → `integer`, etc. |
| Migrations | SQL-step `defineMigration` files in `src/database/migrations/` |
| REST routes | `GET /api/todos`, `GET /api/todos/:id`, `POST /api/todos`, `PATCH /api/todos/:id`, `DELETE /api/todos/:id` |
| Typed client | `client.Todos.list()`, `client.Todos.get(1)`, … |
| MCP tools | `todos_list`, `todos_create`, … (when `mcp.models` opts in) |
| OpenAPI | Model schema in `/openapi.json` |

## Field DSL

| Method | Type | Notes |
|---|---|---|
| `f.id()` | `integer, pk` | — |
| `f.uuid()` | `uuid, pk` | — |
| `f.string()` | `varchar` | `.nullable(), .indexed(), .unique(), .validation(v => v.min(1))` |
| `f.text()`, `f.integer()`, `f.bigint()`, `f.float()`, `f.boolean()` | — | — |
| `f.dateTime()` | `timestamp` | — |
| `f.enum(...values)` | check constraint | — |
| `f.json<T>()` | json | — |
| `f.belongsTo(() => Model)` | FK column | `nullable(), optional()` |
| `f.hasMany(() => Model)` | — | reverse of belongsTo |
