# RBAC

Roles are just data — add `role` to `@kwiva/auth` user store:

```ts title="src/app/models/user.ts"
export const User = defineModel("users", (f) => ({
  id: f.id(),
  email: f.string().validation((v) => v.min(3).max(255)),
  name: f.string().optional(),
  role: f.string().default("member"),
}), { timestamps: true });
```

## Policy interpretation

`definePolicy` rules check roles:

```ts
export const AdminPolicy = definePolicy({
  read(user) { return user?.role === "admin"; },
});
```

## Enforcement

Enforced at: generated routes (permissions), custom controllers (`ctx.can`), channels, MCP tools, tasks.

> [!TIP]
> Roles are optional — `defineAuth` validates `role` if present in `User`.
