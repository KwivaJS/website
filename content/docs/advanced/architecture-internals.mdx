# Architecture Internals

```
Your app (src/app/**, src/ui/**)
  └── @kwiva/* (public API surface, frozen)
        ├── engines (kysely, elysia, better-auth, devalue, marked, croner, ioredis, files-sdk, nodemailer, resend, pg-boss, @modelcontextprotocol/server, evlog, keyv)
        └── CLI (oxlint + build.ts + tsc)
```

## Boundary rules

1. App code imports only `@kwiva/*`.
2. Engines are sealed (`no-engine-imports` lint gate, oxlint).
3. All public symbols are re-exported via barrels (`src/index.ts`).
