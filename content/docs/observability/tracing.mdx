# Tracing

## Spans

Every handler execution creates a span tree:

```
[request] (correlation id)
├── [middleware]
│   └── [handler] → span
├── [db.query] (kysely)
```

## Exporters

- OpenTelemetry exporter (OTLP) — see research
- Console exporter (dev)

`createSpan`, `span`, `withTrace`.
