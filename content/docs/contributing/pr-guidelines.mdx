# PR Guidelines

- PR title: `type(scope): description` (`feat(auth): add OAuth PKCE`)
- Body: what changed, why, how tested, related ADR (if any)
- CI must pass (typecheck + test + build + functionality gates)

See [Releases](/docs/contributing/releases).
