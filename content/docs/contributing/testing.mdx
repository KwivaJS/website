# Testing Standards

## Tests live

`packages/*/src/**/*.test.ts` (colocated).

## Stack

- `bun:test`
- `@kwiva/testing` harness
- `@electric-sql/pglite` (dev)

## Quality gates

- `bun test` per package (in-repo)
- `bun run ci` (typecheck + test + build + functionality)
