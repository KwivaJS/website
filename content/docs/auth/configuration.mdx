# Auth Configuration

File: `src/config/auth.ts`.

```ts
export default defineAuth({
  providers: [emailPassword(), magicLink(), oauth({ id: "google", clientId, clientSecret })],
  session: {
    secret: "dev-only-secret", // non-empty
    maxAge: 604800, // seconds, positive
    cookie: { name: "kwiva_session", httpOnly: true, secure: false, sameSite: "lax" },
  },
  register: { createUser: async ({ email, password }) => ({ email, password }), minPasswordLength: 8 },
  remember: { maxAge: 31536000 },
  rateLimit: { login: { max: 5, windowMs: 60000 } },
  trustProxy: true,
});
```

## `AuthConfig`

| Key | Type | Notes |
|---|---|---|
| `providers` | `AuthProviderConfig[]` | from `emailPassword()`, `magicLink()`, `oauth(provider)` |
| `session` | `AuthSessionConfig` | `{secret, maxAge, cookie?}` — `AuthCookieOptions{name?, httpOnly?, secure?, sameSite?: "lax"\|"strict"\|"none", path?, domain?}` |
| `register` | `RegisterConfig` | `{createUser(input): User, minPasswordLength? (≥1)}`; input `{email, password}` |
| `remember` | `RememberConfig` | `{maxAge?, cookie?}` |
| `rateLimit` | `RateLimitConfig` | `{login?: {max, windowMs}}` |
| `trustProxy` | `boolean \| int ≥ 0` | — |

## Cookie defaults

- Session cookie: `kwiva_session`, httpOnly, secure:false, sameSite: lax, path `/`.
- Remember cookie: `kwiva_remember` (365d default).

## `validateAuthConfig`

Throws `TypeError` on malformed shapes (via `applyConfigSections` in boot seam).

## Key locations

| Symbol | Package | Where |
|---|---|---|
| `defineAuth` | @kwiva/auth | `packages/auth/src/config/` |
| `validateAuthConfig` | @kwiva/auth | same |

> [!TIP]
> For zero-argument defaults, omit `providers` — Kwiva will fail validation if session has no users.
