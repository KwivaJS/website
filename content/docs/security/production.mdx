# Production Hardening

## Env-gated config

- `NODE_ENV=production` — enables HSTS, secure cookies (when configured), no CORS wildcards
- `APP_KEY` (via `kwiva key:generate`) — HMAC secret
- Avoid secrets in source: use env vars, `validateStorageConfig` throws on missing

## Secrets

- `session.secret` non-empty (validated)
- Passwords: `hashPassword` (scrypt)
- Store secrets in env, not files

## Preflight (checklist)

1. `APP_KEY` set
2. Migrations applied
3. Seeders run (for dev data)
4. `storage` configured (production disks)
5. TLS for prod (via reverse proxy)
6. Rate limiting on public routes

## CI placement

- `bun run test` in CI
- `kwiva build` for prod bundle
- `kwiva doctor` in prod health check

> [!TIP]
> Reverse proxy headers: trust X-Forwarded-For via `trustProxy` config.
