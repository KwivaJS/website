# Relations

```ts title="src/app/models/post.ts"
import { defineModel } from "@kwiva/data";

export const Post = defineModel("posts", (f) => ({
  id: f.id(),
  title: f.string(),
  author: f.belongsTo(() => User),
  comments: f.hasMany(() => Comment),
  subscribers: f.manyToMany(() => Subscriber),
  // through
  teamMembers: f.hasManyThrough(() => Member, () => PostToOrg),
  // polymorphic
  attachment: f.morphTo(),
}));
```

## Relation kinds (10)

| Kind | Signature |
|---|---|
| `belongsTo` | one FK column + join via `foreignKey`/`localKey` |
| `hasOne` | reverse belongsTo (one record) |
| `hasMany` | reverse belongsTo (many) |
| `manyToMany` | pivot via `manyToMany(target, {through: Pivot})` or automatic pivot (`posts_subscribers`) |
| `hasOneThrough` / `hasManyThrough` | via intermediate model |
| `morphTo` / `morphMany` | `polymorphic, name`, target optional |
| `morphToMany` | polymorphic many-to-many |

## Modifiers

- `.optional()` — for nullable relations

## Querying

| API | Notes |
|---|---|
| `Post.with("comments")` | eager load |
| `Post.has("comments")` / `Post.whereHas("comments", (q) => q.where(...))` | constraint filtering |
| `Post.withCount("comments")` | add `comments_count` |
| `Post.withAggregate("comments", "sum", "likes")` | `sum/min/max/avg` |
| `Post.whereDoesntHave("comments")` | inverse of whereHas |
| `instance.loadMissing("author")` | lazy load if not loaded |
| `instance.author` | relation handles: `{ load() }` |

## Auto-pivot (manyToMany)

`f.manyToMany(() => Subscriber)` — Kwiva derives the pivot table (`<model>_<other>`) via `kwiva db diff` — appears in `src/database/migrations/`.

## Examples

```ts
const post = await Post.whereHas("comments", (q) =>
  q.where("text", "ilike", "%broken%"),
).withCount("comments").first();
```
