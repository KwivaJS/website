# Data

The data layer: models, query builder, transactions, migrations, seeders, factories.

## Layer diagram

```
defineModel ──► Model Definition ──► model IR (ModelDefinition)
                                       ├─► @kwiva/data (queries, instance API)
                                       ├─► schema → migrations
                                       ├─► @kwiva/http (REST + auto-routes)
                                       ├─► @kwiva/client (typed client)
                                       ├─► @kwiva/mcp (tools, list/get/create/update/delete)
                                       └─► @kwiva/search (FTS)
```

## Key concepts

- **Model as source of truth**: one `defineModel` feeds schema, migrations, REST, typed client, MCP, audit — no drift.
- **Fluent instance API**: `save/update/delete/restore/refresh`, `toJSON`, `isDirty`, `getOriginal`.
- **Global scopes**: attach with `scope()` — applies to every query unless opted out.
- **Tenancy**: automatic query scoping via `tenancy` section + ALS scopes.
