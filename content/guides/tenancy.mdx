# Configure Tenancy

```ts title="src/config/database.ts"
export default defineConfig({
  driver: "pglite",
  tenancy: {
    defaults: {
      mode: "path",
      tenantField: "tenant_id",
      models: "*",
      cache: { scoped: true },
      storage: { scoped: true },
    },
  },
});
```

## Modes

| Mode | URL style | Notes |
|---|---|---|
| `none` | — | track only |
| `fixed` | — | everyone = 1 |
| `path` | `/t/<id>/*` | **recommended for web apps** |
| `header` | `X-Tenant` header | reverse-proxy configured |
| `org` | — | hierarchical |
| `domain` | tenant in domain | hosting-specific |

## Behavior

- Auto-scoped queries (via `tenantField`)
- Storage/cache prefixing via `currentTenant()`

> [!TIP]
> For isolation via `runWithTenant({tenantId})`: see [Tenancy Resolution](/docs/tenancy/resolution).
