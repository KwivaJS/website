# Generate OpenAPI

## Enable

```bash title="terminal"
bun run dev
```

OpenAPI is auto-generated:

1. `bootApp` — `assembleManifest` from routes
2. `mountOpenAPI(app, manifest)` — mounts `/openapi.json` + `/docs`

## Shape

`OpenAPIOptions`: `{title, version, description, path (default "/openapi.json"), specPath, documentation, exclude}`.

## CLI: `kwiva build`

Regenerates manifest + route-tree; OpenAPI is runtime-derived from the manifest.

> [!TIP]
> Try `curl http://localhost:3000/openapi.json` or `/docs`.
