# Frontend 04 — UI Library

**Status**: Baseline · **Updated**: 2026-09-08 · **Docset**: v0.3

`@kwiva/ui-kit` — the component layer on **Base UI** (primitives) + **Tailwind v4** (styling). Ships as the default look for generated Studio screens and page scaffolds; fully replaceable.

## Layering

```
@kwiva/ui-kit
 ├─ tokens      (design tokens: colors, radii, spacing, dark mode)
 ├─ primitives  (Base UI: dialog, popover, select, tabs, toast, …)
 ├─ components  (DataTable, FormFields, Sidebar, Topbar, EmptyState, Avatar, Badge…)
 └─ patterns    (CrudPage, SettingsPage — used by Studio + scaffolds)
```

## Tokens & Tailwind v4

```css
/* src/styles/tokens.css — kwiva preset, overridable */
@import 'tailwindcss';
@theme {
  --color-ember: #e25822;
  --color-ink: #2b2b2b;
  --color-crust: #faf3e8;
  --radius-card: 12px;
}
```

Theme switch via `src/config/ui.ts > theme` and `<Providers theme=…>`; dark mode token-swapped.

## DataTable (the Studio workhorse)

```tsx
import { DataTable } from '@kwiva/ui-kit'

<DataTable
  model={Post}                                   // typed columns from model IR
  columns={['title', 'status', 'author', 'publishedAt']}
  filters={{ status: ['draft', 'published'] }}   // generated from enum field
  search={['title']}                             // full-text where allowed
  rowActions={[{ label: 'Edit', to: p => `/posts/${p.id}/edit` }]}
  bulkActions={[{ label: 'Archive', run: rows => client.posts.archiveMany(rows.map(r => r.id)) }]}
/>
```

- Server-driven pagination/filters through the typed client (list endpoint of the model).
- Policy-aware: actions hidden without `can(...)`.

## Form fields

```tsx
import { Form } from '@kwiva/ui-kit'
<Form model={Post} onSubmit={save.mutate}>
  <Form.Text name="title" />                     // validation + label from field DSL
  <Form.Select enum="status" />
  <Form.Date name="publishedAt" />
</Form>
```

Field metadata comes from `defineModel` (validation, enums, optionality) — forms are derived, not duplicated.

## Accessibility & i18n

- Base UI primitives are the a11y baseline (focus management, aria wiring).
- All components read labels from the i18n catalog (v1.x) — generated scaffolds are translatable by default.

## Usage rules

- Apps may use `@kwiva/ui-kit`, plain Tailwind, or their own system — the framework only requires the token surface the Studio uses.
- No component library leaks into data layer or server code.
- Preact mode is supported (components avoid React-only APIs).

## Styling conventions

- Tailwind v4 utility-first; tokens as the only cross-package contract.
- `src/ui/styles/` holds app-level css entries; generated by `kwiva new`.
- The build pipeline handles css via rolldown css plugin + Tailwind's oxide scanner (dev uses Tailwind v4's fast engine).
