One grammar for everything you build.

03Architecture

Five layers. One hard boundary.

04Source of truth

Define the model. Derive the plane.

One defineModel becomes a typed intermediate representation. Everything below it is generated — nothing is written twice, so nothing drifts.

src/app/models/post.ts
export const Post = defineModel("posts", (f) => {
  id: f.id(),
  title: f.string(),
  body: f.text().optional(),
  status: f.enum("draft", "published"),
  author: f.belongsTo(() => User),
  comments: f.hasMany(() => Comment),
}, { timestamps: true });

models/*.ts → IR (typed intermediate representation) →

  • 01DB schema + migrations + seeders@kwiva/data
  • 02Typed REST API — 5 routes per model@kwiva/http
  • 03Typed RPC client SDK@kwiva/client
  • 04Studio — generated operations UI@kwiva/studio
  • 05OpenAPI specification@kwiva/http
  • 06MCP tools for AI agents@kwiva/mcp

→ no drift between types, API, and database
